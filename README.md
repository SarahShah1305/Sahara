# Sahara

A hospital capacity and referral app for Hyderabad, Sindh.

## Status

Hackathon prototype. Hospital capacity shown in the app may be demo data unless explicitly verified.

## Run the mobile app

```sh
cd mobile
npm start
```

Scan the Expo Go QR code with your phone. The current screen uses clearly labeled sample hospital and capacity data; it is not connected to live hospital systems.
